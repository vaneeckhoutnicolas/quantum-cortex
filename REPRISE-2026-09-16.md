## Working rules (unchanged, non negotiable)

Thresholds never move. One variable per run. No prediction of a run's outcome, ever. A failure is a result and is attributed before the next run. Every claim: the seven rule gate (whitepaper §2.6); "gated" needs three seeds. Before interpreting a number, re read the code of the lever that produced it (the v5 lesson). A source that lives in a chat window is not a source. Two parallel readings are settled by the source, not by the more confident one. One instance graves a run. Nothing not graved is claimed, in any document. English in the repository, French with the founder; no hyphens in prose written for him, no unexplained acronyms; the Molaison dissociation is defined at its first mention in every document (Henry Molaison, hippocampus removed in 1953, no new episodic memory, skills intact).
