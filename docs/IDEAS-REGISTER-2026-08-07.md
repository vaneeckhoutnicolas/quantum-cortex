### NOW-1 · Oracle in pretraining, not bolted on — *the trap everyone would hit*
**What:** train with the C3 oracle channel active from the start: inject controlled distribution shifts and exogenous event tokens *during pretraining*, so the model learns to condition on them. **Why:** an input channel the model never saw in training is noise at inference; C3 only works if it is a curriculum citizen. **Test:** oracle-shift recovery of oracle-trained vs oracle-naive model, equal budget. **Status:** Established principle (conditioning channels), novel application. **Impact:** N1's data pipeline must already reserve the token space for oracle events.

### NOW-2 · Speculative graft — the C5 economics engine
**What:** invert speculative decoding: standalone, the cortex *is* the final decoder; plugged, it drafts and the grafted big zone verifies/overrides **only the spans where the cortex's own uncertainty (its energy) is high**. **Why:** one mechanism yields "fast alone, strong together", with cost proportional to difficulty — the demo is a cost/quality curve nobody ships today at the architecture level. **Test:** quality-per-dollar vs always-big and vs always-small baselines. **Status:** Established components (speculative decoding, cascades), Frontier combination (uncertainty-gated, energy-driven). Maps to C5 + C6 telemetry.

### NOW-3 · Matryoshka internal states
**What:** train hidden states matryoshka-style so any prefix of the state vector is a valid lower-resolution reading. Grafted zones of different sizes read the *same* state at their own fidelity; the persistent memory tier stores truncated states cheaply. **Why:** solves standalone-vs-plugged representation compatibility elegantly; shrinks journal-backed memory cost. **Test:** graft quality at 25/50/100% state resolution. **Status:** Established (matryoshka representation learning), Frontier as an internal-state discipline. Maps to C2b + C5.

### NOW-4 · Runtime matrix at release day — and the compute-abstraction reality
**What:** the launch checklist includes: GGUF quantized artifacts (llama.cpp), vLLM support, HF `transformers` remote-code modeling file, and the OpenAI-compatible server. Architectural rule derived from it: custom ops must either stay expressible in llama.cpp's op set or carry a budgeted kernel plan. **Reality check (systems engineer):** the hardware-agnostic layer *exists* and is the industry's active battleground — ggml (one codebase → CPU/Metal/CUDA/Vulkan), ONNX Runtime execution providers, Triton/MLIR/IREE compiler stacks, Modular MAX/Mojo. Any architecture can emulate any other ("zeros and ones"); what is **not** solved is *performance portability*: LLM inference is memory-bandwidth-bound, and abstractions that hide the memory hierarchy pay a large tax — that is where the "quintessence" of a resource is lost. **Posture:** consume these layers, never build one (that is a compiler company's decade, not ours); the portable-ops rule above is how the cortex stays welcome on all of them. **Status:** Established engineering. Maps to C6.

### NOW-5 · The live-oracle demo — the wow
**What:** a public interactive demo (HF Space class) where the user *injects oracle events mid-generation* — a slider, a news feed toggle — and watches the reasoning bifurcate, with the energy/uncertainty visualized live. **Why:** no released model lets users perturb its reasoning through a first-class channel; this makes gray states *visible*, which is the adoption story. **Status:** Established tooling, novel demo object. Gate: only after C3 passes its ablation.

### RES-13 · Latent recursive refinement — depth as a dial, not a parameter count
**What (TRM-credited):** a small core recursing in latent space with halting — test-time compute scales by *cycles*, not weights: the existing extreme of capability-per-parameter (a 7M, 2-layer network beating far larger models on ARC-class puzzles). Our twist candidates, coherent with the stack: recursion depth **modulated by the endocrine bus** (stress → more cycles on high-stakes spans) and by **C4 contract criticality** (typed outputs earn deeper refinement); depth becomes a per-span dial the homeostat can budget. **Honest caveats (kept from the founder's own brief):** TRM's regime leans on ~1000× per-example augmentation and puzzle domains; transfer to language modeling is unproven — which is exactly the ablation. **Test:** recursive core vs feedforward control at equal params on the declared capabilities and continuity triad; the depth-dial curve (quality vs cycles) is the deliverable. **Status:** Frontier. Maps to D3, RES-9, C4; baseline citations: TRM, and its own shipped transformer control.

### RES-14 · Data-portfolio valuation — the mix as a portfolio, weights as a measured β
**What (founder, 2026-09-06):** a source's weight in the data mix should not stay a hand-declared constant; it should converge toward the source's **measured marginal contribution to declared capability** — a *data-β*, exactly as a portfolio β measures an asset's marginal contribution to the portfolio. The mix *is* a portfolio: some sources co-vary (redundant, like correlated assets), others diversify (complementary — the real gain). Two measurable objects: (a) per-source **marginal value** = ∂(capability)/∂(weight), the rigorous form being **data-Shapley** (mean marginal value over compositions); (b) an **inter-source covariance/affinity matrix** — which sources are redundant vs diversifying. **The cross-scale bet:** the same associative/magnetism operator that powers C2 (RES-1/RES-2) — a learned affinity between representations — is a candidate for measuring inter-source affinity; magnetism as one primitive at token scale (C2), source scale (the mix), and possibly organ scale (D16 interactions). **Sequencing (measure-first, non-negotiable):** a data-β presupposes the very infrastructure being built — the composition layer (ADR-005) plus a populated Pareto frontier (D16). It is a *result* read from the frontier, not an input. ADR-005 accordingly makes the mix weight a **pluggable resolver** (constant now; a β-estimator behind a clean seam later); this entry is not promoted into the engine until it can be measured. **Credit:** data-Shapley and modern portfolio theory are established; ours is wiring them onto the magnetism operator and the continuity frontier. **Test (when infra exists, post-W1):** estimate per-source β from frontier points; verify β-weighted mixes predict capability better than uniform weights at equal tokens — the β-vs-uniform curve is the deliverable. **Status:** Frontier, infrastructure-gated. Maps to RES-1/RES-2 (magnetism), NOW-7/ADR-005, RES-12 (distilled sources as portfolio components), D16.

### RES-15 · Meta-tokens — structure carried in the stream, with a three-phase lifecycle
**What (founder, 2026-09-06):** a **meta-token** is not a data byte and not an association buried in the weights — it is a token that *carries structure about other tokens*, in the stream, addressable by the model. The category is already present, unnamed: the 8 reserved **oracle** ids (NOW-1) and the typed **span references / schema ids** (RES-8) are meta-tokens that did not know they were. The founder's contribution: (a) recognising the unified primitive, and (b) a **three-phase lifecycle** — a producer→consumer economy across the architecture:
- **Origin/source** (static, upstream): provenance — "this span is from the *math* source", "this oracle-event is signed by source X". Inscribed by the composition layer (ADR-005) and signed ingestion (NOW-9). Read-only. **Enters training → must be decontaminated, counted, controlled** (else the model cheats by reading the label).
- **Process** (transient, in-flight): the *state of computing* — "oracle flipped to gray", "span under recursive refinement (RES-13)", "hyperdirect veto fired", "effort depth ×3 (ACC)". **Runtime-only — must never leak into training data.**
- **Result** (produced then consumed): emitted by a step, absorbed by the next or by the journal — "cites span Y (RES-8)", "salience 0.8 (amygdala)", "credited retroactively (RES-11)". **Ephemeral — must never persist.** Bridge to **D4.8**: a result meta-token never consumed (never credited, recalled, consolidated) is by definition noise — evicted by the tribunal.
**Three guards (critical one first):** the three lifecycles impose **three distinct decontamination policies** — conflating them is a *security* bug, not an imprecision. Vocabulary budget is tiny (8 oracle ids) → a hierarchy (a "meta" id + subfield) or out-of-vocab addressing. Each concrete meta-token is a hypothesis measured on the frontier. **Test (per instance):** provenance meta-token on/off at equal data — better conditioning without cheating on the label? **Status:** Frontier, organising framework. Maps to NOW-1, RES-8, RES-11, RES-14, ADR-005, D4.8.

### RES-16 · Content-addressed hierarchical consolidation — one law at every scale
**What (founder, 2026-09-06):** *what has been computed and is still valid is never recomputed; what changed recomposes only its delta; the content hash decides.* One law unifying five mechanisms treated separately, mapping onto the memory hierarchy:
- **Short-term** (working memory) = in-session C2 state + process meta-tokens (RES-15).
- **Medium-term** (hippocampal consolidation) = the C2b journal + consolidation phases (RES-9) — an episode is recalled, not recomposed.
- **Long-term** (cortical sediment) = the **weights** — stable knowledge is baked, not recomposed.
- **Data-composition cache** = the same law over data (Olmix mixture-reuse, ADR-005 D3): an unchanged-hash subtree is pulled from cache.
- **Meta-token lifecycle** = the same law over the stream (RES-15).
**Temporal dynamics, named by the founder:** **primacy** = consolidation *priority* (what consolidates first is the anchor; serial-position curve, Rev7.b, gains its role); **reminiscence** = **reconsolidation via reverse replay (RES-11)** — a result resurfacing and rising in salience after an outcome validates it. **Guard (measure-first):** the value is the *unifying principle*, not a new module — the five mechanisms ship at their own waves (measured separately); premature fusion would be a speculative framework the ledger does not test. **Status:** organising principle (D16-level, cross-cutting), not a single ablation. Maps to D4.8, RES-9, RES-11, RES-14, RES-15, ADR-005 D3, Rev7.b.

### RES-17 · The type×state taxonomy — static type, dynamic processing-driven state
**What (founder, 2026-09-06):** every object in the system lives at a point in a **two-axis grid**: a *type* (the static taxonomy — what it is: a journal entry, a meta-token, a memory, a span, a data operator) and a *state* (the dynamic taxonomy — where it is in its lifecycle, which *transitions as the processing acts on it*). Consolidation, eviction, consumption, refinement, memory promotion, reminiscence are all **state transitions in this grid**, triggered by processing. The insight unifies mechanisms already graved separately: D4.8 (admitted → live → consolidated **or** noise-and-evicted), RES-15 (origin → process → result-consumed-or-noise), RES-16 (short → medium → long-term, with reminiscence = upward transition via RES-11), RES-8/RES-13 (raw → refined → contracted → referenced). **Why it matters:** carrying (type, state) explicitly makes the system **inspectable** (trace *why* an object is where it is — provenance), **governable** (transitions obey D4.8 guards, RES-9 budgets), and **measurable** (how many objects stuck in a state? how many evicted?) — the structure becomes *legible* instead of buried in the weights. Even a C2 layer's training is a micro-instance (no-op → learning → contributing). **Three guards:** *descriptive not prescriptive* (name the states objects traverse; do not force every mechanism into one universal state machine — the value is a shared vocabulary, not a framework that replaces the wave-scoped mechanisms); *minimal carried state* (each object bearing (type,state) costs memory/complexity and risks leaking across RES-15's three decontamination policies — keep only the transitions that matter); *principle not brick* (organising frame, implemented only where a wave exercises it). **Status:** Frontier, organising principle (D16/RES-16-level, cross-cutting). Maps to D4.8, RES-8, RES-9, RES-11, RES-13, RES-15, RES-16, ADR-005.

### RES-18 · Multi-path C2 — a memory router on a control floor, consolidating and self-healing
**What (founder, 2026-09-07, a three-message synthesis that unifies seven already-graved mechanisms; validated by the ablation data — the upper envelope beats the best single path by +6%, and the control wins 3 tiers, making the floor *necessary* not cosmetic):** C2 stops being *one* associative memory, or a choice between Hopfield and delta. It becomes a **router of memories** with three properties, born from the per-tier result (Hopfield wins most, delta wins intermediate regimes, control wins long sequences — each has a domain, so *don't choose, arbitrate*):

1. **Control as the guaranteed floor.** The vanilla control (no memory) is always available. On any span, a memory is used *only where it beats the control*; if it drops below, route away; if all are below, use the control. C2 therefore **can never degrade the model** — the C2-level twin of the no-op-at-init guard. Falling to the control on a span is a *result* ("no memory helps here"), not a failure. **The data proves this is needed: the control won 3 of 12 tiers.**
2. **Routing regime follows consolidation (hard-on-learned, soft-on-new).** Where the router has *learned* which path wins for a span-type (confident, stable), it routes **hard** — one path, pre-computed, minimal cost. Where unsure, it routes **soft** — compute + weight, generating the learning signal to harden later. The system **migrates soft→hard as it learns**: mean cost *falls* while precision *rises*. This is RES-16 (working→consolidated) on the router, the LC explore/exploit dial (endocrine), and basal-ganglia habit formation, at once. **Guard:** the hardening threshold is *declared, measurable, conservative* — hardening too early freezes a possibly-wrong choice; better stay soft too long than harden an error (mirrors D7: conservative except on NaN).
3. **The circuit breaker as a re-routing fallback (not an on/off switch).** When an active path degrades/diverges, the breaker (D7) does not kill — it **re-routes to the best remaining path above the control**, else the control. Reciprocally (the founder's question): if Hopfield breaks, fall to delta *iff delta is above the control there*, else the floor; if delta breaks, fall to Hopfield or the floor. The breaker **re-softens** the decision (RES-16 reminiscence — a consolidated choice resurfacing under change). This *completes the hyperdirect veto* (basal-ganglia): the veto hands control back to the router, it does not leave a void. **Guard:** a **declared hysteresis** on the fallback (cooldown / require a *clear* recovery above the control) prevents flapping between paths (the bounded-retry discipline of D7 applied to routing).

**The unification (the point):** not three ideas — *one system* branching seven mechanisms graved separately: **C1** (router), **RES-4** (confidence routing), **RES-16** (consolidation + reminiscence), **RES-9 endocrine** (explore/exploit), **basal-ganglia** (habit + hyperdirect veto), **circuit breaker D7**, **RES-17** (a span transitions hard↔soft↔fallen-back). The project was the same system seen through seven windows. **Test (when built):** router AUC ≥ max single-path AUC by construction (the ablation shows the ceiling: +21% vs control, the upper envelope); mean routing cost falls over training; no oscillation under hysteresis. **Status:** Frontier — the design of C2 proper. Maps to C1, RES-4, RES-9, RES-16, RES-17, ADR-006 D7/D8, brain-atlas basal-ganglia/endocrine.

**Implementation (2026-09-07):** 🟢 **complete — the four-slice router (A→B→C→D) is built and green.** `cortex_c2/`:

## Tier RES — research candidates (Frontier; each one is an ablation)

### RES-1 · One energy function to unify zones, magnetism, volatility
**What:** a candidate formulation making C1+C2+C3 a single mathematical object. Sketch (to be made rigorous before any claim):

    p(z_t | x, M, o_t) ∝ exp( − [ E_zone(z_t; router, trust) + E_mem(z_t; M) + E_inv(z_t; contracts) ] / T(o_t) )

where `M` is the associative memory, `o_t` the oracle state, `T(o_t)` an oracle-driven temperature, and — the interesting variant — the oracle may also **reshape the landscape** (add/remove attractor terms in `E_mem`) rather than only heating it. Gray state = the distribution itself, not a sampled branch. **Why:** one equation the whitepaper can stand on; each term is independently ablatable. **Test:** landscape-reshaping vs temperature-only on oracle-shift recovery. **Status:** Frontier; the sketch is a hypothesis, not a result.

**Implementation (2026-09-07):** 🟢 implemented as the C2 `HopfieldMemory` layer — and it **wins the first MQAR ablation** (+14% AUC vs control, ~3× cheaper than delta). The 2026-08-07 "hypothesis, not a result" above is now *superseded by measured data* (kept per errors-noted-never-erased). Full result: `metrics/mqar/mqar-ablation-final-2026-09-07.json`.

### RES-2 · Journal-backed test-time memory ("a model that remembers your project")
**What:** Titans-class fast-weight memory that writes on **surprise** — but with the QM per-project encrypted journal as the persistence substrate: surprise moments are journaled (agent-side, I13) and re-loaded as fast-weight state per project scope. **Why:** turns QM's existing journal into a literal long-term memory organ; standalone models forget, this one resumes. Strong differentiation + strong QM flywheel. **Test:** cross-session task continuation vs stateless baseline. **Status:** Frontier (test-time training is active literature; the journal substrate is the novel part). Maps to C2b, respects the trust boundary by construction.

### RES-3 · Geometric memory: hyperbolic and mixed curvature — *the honest answer to "3D/4D tensors"*
**What:** the leverage is not tensor rank (transformers already compute in 4D tensors); it is **geometry**. Hyperbolic volume grows exponentially with radius, so hierarchies embed with low distortion — magnetism then respects concept taxonomy natively: a parent concept attracts its children. Concretely: (a) associative keys/attractors live on a **Lorentz-model** hyperbolic manifold (numerically stabler than the Poincaré ball; fp16 breaks near the ball boundary — a known trap, anticipated here); (b) the full version is **learned mixed curvature**: a product manifold H^a × S^b × E^c — hyperbolic for hierarchy, spherical for cyclic/similarity structure, Euclidean for the rest — with curvatures learned per component and reported in the ledger. That is the rigorous form of the "3D/4D" intuition: not more dimensions, a **learned curvature signature**. Scope discipline: only the C2 memory layer changes geometry; everything else stays Euclidean, so the ablation is clean. **Precedent, stated honestly:** hyperbolic embeddings are established (Poincaré embeddings, 2017; large-scale recommender systems have exploited them) — the claimed novelty is narrower and testable: a hyperbolic/mixed-curvature *associative memory inside a language model*. **Test:** hyperbolic vs Euclidean vs mixed-curvature associative layer at equal params on hierarchy-heavy recall + tree-distortion metrics. **Status:** Frontier. Maps to C2.

### RES-4 · Trust-weighted routing — Kern's slashing inside the weights
**What:** each zone carries a learned trust score updated by an auxiliary loss: a zone whose confident contributions correlate with errors loses routing weight (an epistemic bond, slashed on equivocation — the Kern attestation mechanism transposed into training). Extends to grafted zones at inference via C6 telemetry. **Test:** robustness under deliberately corrupted experts vs vanilla gating. **Status:** Frontier. Maps to C1 + C5 + the trust-score vocabulary already in the glossary.

**Implementation (2026-09-07):** 🟡 partially exercised — the RES-18 router (`cortex_c2/`) carries per-path confidence in `RouteDecision`, and that confidence now *drives consolidation* (the ConsolidatingController hardens only confident, stable decisions — Slice C). The full trust dynamics (an auxiliary loss slashing paths whose confident contributions correlate with errors, corrupted-expert robustness) land with training on real spans.

### RES-5 · Heterogeneous placement by magnetism — the resource pool done right
**What:** treat hardware backends the way the router treats zones: a **pool of measured resources**. Each backend (CPU/ggml, consumer GPU, big GPU, NPU) carries live-measured throughput, cost and energy; a placement scheduler — same scoring philosophy as QM proposal magnetism — assigns work per request: NOW-2's draft runs on cheap silicon, verification on strong silicon, memory tiers spill by locality. The model itself stays device-blind (frameworks already provide that); the *scheduler* is deliberately device-aware, because pretending silicon is uniform is exactly how the "quintessence" of each resource is lost — Go's scheduler wins by measuring and work-stealing, not by pretending cores are identical. **Test:** tokens-per-dollar and tokens-per-joule vs single-backend serving at equal output quality. **Status:** Frontier (primitive forms exist — llama.cpp CPU/GPU offload, disaggregated serving; the per-request, energy-signal-driven, magnetism-scored placement is the novel combination). Maps to C5 + C6 + NOW-2. *Rev3 evidence:* kimi-k3-in-c ("memory is a dial"), prima.cpp/Halda, PowerInfer-2 neuron clusters — the pool thesis now has three independent living exhibits.

### RES-11 · Reverse-replay credit assignment along the journey
**What (from the hippocampus deep dive, 2026-08-08):** biological memory replays trajectories in *both* directions — forward for consolidation (already RES-9), and **backward after outcomes**, propagating value to the steps that led there. Transposed: when an episode closes with a scored outcome (ledger metric, user verdict, contract pass/fail), the journal trajectory is walked **in reverse**, updating the **salience and trust contributions of each step** — memory-level credit assignment with no backprop-through-time, purely as journal metadata updates. Combined with RES-9's forward consolidation, the journey (the founder's day-one word) gains its full biological life cycle: traversed, reverse-scored, consolidated. **Credit:** reverse replay and its credit-assignment reading are established neuroscience; experience replay with prioritization exists in RL (credited). **Our claim, testable:** outcome-driven reverse updates over a *content-addressed, schema-tagged journal* feeding retrieval weights and trust scores in an LLM memory system — no found precedent. **Tests:** long-horizon task suites with delayed outcomes — retrieval precision of outcome-relevant steps vs recency/salience-only baselines; trust-score convergence speed under noisy episodes. **Status:** Frontier (combination). Maps to C2b, RES-2, RES-4, RES-8, RES-9.

### RES-10 · The connectome as a first-class parameter — neurodiversity as design space
**What (founding insight: Nicolas, 2026-08-08):** the graph of inter-zone connections — who talks to whom, at what width — stops being an implicit all-to-all and becomes a **declared, ablatable, eventually learnable parameter**. Three mechanisms: (a) **dual-stream hemispheres with a bottlenecked commissure** — a limited-capacity broadcast channel between zone groups where outputs compete for access, forcing abstraction at the exchange (Global Workspace Theory, credited); (b) **dedicated arcuate-style links** — high-bandwidth paths between specific zone pairs instead of uniform connectivity, paid from a declared wiring budget; (c) **connectivity profiles as an ablation family** — local-dense vs long-range-dense wirings at equal parameters, each measured into a per-capability *cognitive-style profile*. Anatomical grounding: cortical areas differ in cytoarchitecture and their geometry varies between individuals — heterogeneity and inter-individual profiles are biological facts. Scientific honesty: the autistic-connectivity literature is heterogeneous; the transposed **principle** is that profiles differ and that diversity is functional — never a clinical claim. **Tests:** connectome sweep at equal params → capability-profile matrix (does long-range density trade systematicity against generalization, measurably?); commissure-width sweep → abstraction quality vs latency. **Status:** Frontier (GWT implementations exist, credited; a declared inter-expert connectome with profile ablations in an LLM is our combination). Maps to C1, C5, RES-9, Rev7.a.

### RES-9 · The endocrine axis — a neuromodulation bus
**What (Nicolas's brain prompts, 2026-08-08, made mechanical):** a low-dimensional **global modulation vector** (stress / arousal / reward-like channels) broadcast to every gate in the system, plus the regulatory organs around it:
- **Cortisol → the stress scalar.** Emitted by the oracle channel (C3) or by degraded telemetry (C6: failures, low trust): it simultaneously tightens C4 contract strictness, lowers sampling temperature, raises the NOW-2 escalation threshold (verify more), and **boosts the salience-write gain** — the biological tradeoff (stress consolidates the salient, narrows the rest) implemented as one broadcast value.

**Credit where due:** neuromodulated plasticity is an existing research thread; systems consolidation and attention sinks are documented. **Our claim, testable:** the unified bus — one broadcast modulation vector wired to oracle + telemetry, acting coherently on routing, decoding, contracts, escalation and memory writes in an LLM — has no found precedent. **Tests:** stress-response curve (accuracy on high-stakes items vs output diversity under injected stress — the tradeoff must be measurable, not assumed); consolidation ablation (with/without replay phase on long-horizon recall); serial-position curve benchmark (Rev7.b). **Status:** Frontier (combination). ### RES-8 · Differential decoding under dynamic span contracts
**What (requirement of 2026-08-08, decomposed):** (a) **never regenerate what exists** — the decode loop gains a **typed reference operator**: outputs may *cite* content-addressed spans (context, journal, prior outputs) through reserved token ids (the NOW-1 discipline extended) instead of re-emitting them — referenced spans are exact by construction and cost ~zero generated tokens; on edit-heavy tasks the model emits a **typed diff** over existing spans. ### RES-7 · Ternary cortex — playing the numerical base where it is actually free
**What:** the digit level is not free (silicon is binary; ternary hardware died with Setun, radix economy notwithstanding) — but the **representation** is. The genuinely novel question is ours alone: **do C1–C4 survive ternarization?** In particular, does the delta-rule/associative state (C2) keep its error-correcting behavior when weights are ternary — no literature answers that. Thesis sharpening recorded: the declared metric family gains **capability per bit** next to capability per parameter — the honest metric for edge deployment. **Adjacent facts noted, not entries:** NF4's non-uniform levels are an information-theoretic "base" choice (Established, serving-side, K6 spirit); log-number systems turn multiplies into adds but live in research silicon; residue number systems live inside FHE stacks (SPEC-4's plumbing). **Test:** ternary vs fp16 control at equal params/tokens on the declared capability benchmarks + perplexity; report capability-per-bit. **Status:** Established base (BitNet), Frontier question (our components under ternarization).
