# MQAR ablation artefacts (NOW-6, ADR-006 Slice C)

Architecture-bench results for the C2 ablation on Multi-Query Associative Recall,
kept separate from the run-v1 language-training ledger. Each file holds the three
accuracy curves (control / hopfield / delta) over the difficulty curriculum, their
AUC, the per-tier winners, the **upper envelope** (the ideal RES-18 multi-path
router), and where relevant a capacity sweep.

## Key result (final-2026-09-07)
- AUC: hopfield 0.1206 (+14%), delta 0.1083 (+2%), control 0.1062 — verdict **advances**.
- Per-tier: hopfield 6, delta 2, control 3 — each path has a domain.
- Upper envelope (RES-18 router) = **+21% vs control, +6% over the best single path**.
- Hopfield capacity sweep → **structure-limited** (more slots do not help).

The signal is the whole curve (AUC), not a single threshold (the v1 "held" was a
0.5-cutoff artefact). `LATEST.json` points to the most recent run. Generated by
`python -m cortex_eval.ablation_mqar`. Circuit breaker (D7) per tier. NOW-6.
