# MQAR ablation artefacts (NOW-6, ADR-006 Slice C)

Architecture-bench results for the C2 ablation on Multi-Query Associative Recall,
kept **separate** from the run-v1 language-training ledger (MQAR is an
architecture probe, not a language run). Each `mqar-ablation-*.json` holds the
three accuracy curves (control / hopfield / delta) over the difficulty
curriculum, their drop-off points, the gap vs control, and the verdict.

The signal is the **gap between drop-off points** (D16 + the curve principle):
where each variant's accuracy first falls below threshold as difficulty rises.
`LATEST.json` points to the most recent run.

Generated by `python -m cortex_eval.ablation_mqar` (or the Kaggle notebook
`notebooks/n2_mqar_ablation.ipynb`). The circuit breaker (ADR-006 D7) aborts any
diverging tier. These are open, versioned deliverables (NOW-6).
